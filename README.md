# CS2-Bot-Randomizer
CS2-Bot-Randomizer is a plugin based on CounterStrikeSharp that allows each bot to have their own agent model, music kit and avatar.
# Features
1. Assign each bot their own T/CT agent model and avatar

2. Allocate an MVP music kit to each bot

3. added gun weapon skins to each bot

# Installation
1. Download the latest BotRandomizer.zip from [Releases](https://github.com/ed0ard/CS2-Bot-Randomizer/releases)

2. Decompress it and upload the folder to `game/csgo/addons/counterstrikesharp/plugins` on your server

3. Restart your server
